# ScoopSwift Responsive Website

Responsive single-page website based on the supplied ScoopSwift mobile mockups.

## Included

- Desktop, tablet, and mobile layouts
- Supplied ScoopSwift logo and mascot artwork
- Mockup-matched “Book Today + Stats” card
- Two-part FAQ layout with working accordions
- Responsive navigation
- Interactive quote form demo
- Service plans and service-area sections

## Open locally

Open `index.html` in a browser. Keep the `assets`, `styles.css`, and `script.js` files in the same folder structure.

## Before launch

Connect the quote form in `script.js` to your email, CRM, or booking endpoint. Replace placeholder social and privacy-policy links with live URLs.


Latest update: removed the decorative hamburger icons from the booking/FAQ mockup cards and merged both FAQ parts into one responsive FAQ section.
